# Michael Dunkelman portfolio — editorial V13

Static multi-page portfolio concept containing:

- A reduced-noise homepage
- Four complete case studies
- An expanded About page
- Responsive navigation and a compact case-study chapter navigator
- Accessible image viewer with fit, zoom, and full-size controls
- Responsive layouts, keyboard focus states, reduced-motion support, and lazy-loaded evidence

## Preview locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173` from inside the `portfolio-editorial-v11` directory.
